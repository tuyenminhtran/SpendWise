# SpendWise

## Overview

SpendWise is a personal expense management Android application that helps users record, categorize, and track their daily financial activities.

This project was developed as part of a Software Engineering course, focusing on system design, clean project structure, and practical application development.

---

## Objectives

* Help users manage personal finances more effectively
* Apply Software Engineering concepts in a real project
* Practice Android development with structured architecture
* Build a simple but functional expense tracking application

---

## Features

* Add income and expense transactions
* Categorize transactions (food, shopping, education, etc.)
* View transaction history
* Calculate total income, expenses, and remaining balance
* Simple and user-friendly interface

---

## Technology Stack

Platform: Android
Language: Kotlin
UI Toolkit: Jetpack Compose
Architecture: MVVM
Database: Room Database
IDE: Android Studio
Build Tool: Gradle
