# SpendWise

## 📌 Introduction
**SpendWise** is a personal expense management application that helps users record, categorize, and track their daily income and expenses.  
This project is developed as a **Software Engineering course assignment**, focusing on core system functionality, clean project structure, and practical use cases.

---

## 🎯 Objectives
- Help users manage personal finances effectively
- Practice software engineering concepts through a real-world application
- Apply basic UI/UX principles and structured project organization
- Build a simple but functional expense tracking system

---

## ✨ Main Features
- Add income and expense transactions
- Categorize expenses (e.g. food, education, entertainment, etc.)
- View transaction list
- Calculate total income and expenses
- Simple and user-friendly interface

---

## 🛠️ Technologies Used
- **Platform:** Android
- **Programming Language:** Java / Kotlin
- **IDE:** Android Studio
